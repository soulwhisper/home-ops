# 03 阶段计划（P0–P5）

总原则：**GitHub = 唯一控制面 + 权威仓库**，git = 审计底座，**原生事件驱动（零轮询胶水）**，
先手动跑通再自动化。CI 分工定稿：**GHA = 验证门禁 + agent 工作流唯一执行面；
Woodpecker = 数据面 cron 专属；Forgejo Actions 不复活**。
用户前置人工项全部见 `00-用户前置清单.md`（A/B/C 配置 + D 拍板 + E 实测）。

## P1 Executor 手动跑通（1–2 天）

- 任务卡模板 `docs/tasks/TEMPLATE.md`：目标、范围文件清单、**可执行 shell 验收命令**、
  禁动清单、回滚一句。杜绝模糊词为硬性字段。
- 任务卡载体 = GitHub issues（D4）。
- 工作站 omp 干 3 个真实任务（建议：renovate 配置整理 / 某 app HelmRelease 升级 /
  ai.md 漂移修复若 P0 未做），每个走全链路：分支→commit→PR→CI 绿。
- **验收**：3 PR diff 人读无越界、CI 全绿、验收命令真实执行过。
  这 3 个 PR = P2 金标集种子。

## P2 Reviewer 上线（0.5–1 天 + 2 周 shadow）

见 `02-reviewer选型.md`。**GHA 承载，`pull_request` 原生触发**（GitHub 原生路线的红利：
轮询胶水整段删除）。前置依赖：P0-2（action platform 实测）、P0-3（tool-calling 实测）、
D3（`.woodpecker/` 重复管线清理，消除双权威遗留物）。
`AI PR Review` 门禁 shadow 后才挂进分支保护（D5）。

## P3 Executor 自动化 + 停滞心跳（1 天）

全部走 **GHA 原生事件**（dispatch/issue_comment/schedule 全有，无需任何自造桥）：

- **agent-job**：`workflow_dispatch`（inputs = 任务卡 issue 号）→ job 拉任务卡 →
  agent 执行（`GITHUB_TOKEN` contents:write 原生，免 PAT）→ push 分支 → 开 PR。
  预算护栏 = job timeout（GHA 上限 6h）。
- **派活/叫停/@bot**：hermes 飞书指令 → 建任务卡 issue → dispatch agent-job；
  叫停 = cancel run（GHA API）+ 飞书确认回执；`/ai-review` 类评论命令走 `issue_comment` 事件。
- **停滞心跳**：GHA `schedule` 工作流——X 小时无新 commit/分支 **且** 无运行中
  agent-job → POST hermes webhook route（`/p/ops/webhooks/stall-alert`，HMAC，
  照 frigate-alert 模式）→ 飞书。进程死（run failed）与停滞（无产出）分开报。
  schedule 延迟与 60 天停用条款：home-ops 有 renovate 周更，免疫。
- **集群外兜底（ADR-02 欠账，D7）**：NAS 部署 Gatus——probe GitHub API +
  收 GHA cron 的 external-endpoint 心跳，失败 → Pushover/飞书。
  补 forgejo-runner 归档后消失的 out-of-tree 观测。

## P4 决策门 + 呈现层（半天起）

- **决策门**：`micro` 车道 constrained JSON `{choice, confidence}`（2.6B 分类器，
  thinking disabled，现成模式）；多选项/重上下文升 `omni`。阈值 0.8，低置信→
  飞书审批卡片（见 04）。**reflex 不动**：维持 advisory-only，影子数据集继续累积。
- **图片/视频渲染**：见 `05-图片视频渲染.md`；渲染 venue = GHA runner
  （ubuntu-latest + apt ffmpeg / headless Chrome，serverless）。
- diagram-design 先作工作站 omp skill 手动用；进 CI 后守"源进 git、产物是
  build artifact"铁律。

## 工程量

P0 半天 + P1 1–2 天 + P2 1 天 + P3 1 天 + P4 半天 ≈ **3–4 天**。
**新增常驻面 = 零**（无 runner、无轮询胶水、无新服务；Gatus 是 ADR-02 欠账而非本计划新增；
Woodpecker/Forgejo 维持存量职责）。相比初稿（4 天 + runner 加固 + 轮询胶水 + 双轨纪律）
净删：forgejo-runner 复活与加固、mirror 轮询、Forgejo 分支保护/API 门禁、双轨 CI 纪律。
